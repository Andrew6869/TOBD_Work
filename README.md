# Курсовой проект по ТОБД: Анализ потребительских предпочтений

**Тема:** Исследование изменчивости потребительских предпочтений для обнаружения поведенческих паттернов во времени.

---

## О проекте

Проект выполнен по методологии **CRISP-DM** и охватывает полный цикл анализа данных: от постановки бизнес-целей до разработки интерактивного аналитического дашборда. 

**Основные этапы:**
- **2.1. Цели и гипотезы:** определены 4 бизнес-цели, границы исследования и 5 аналитических гипотез (H1–H5).
- **2.2. Источники данных:** собраны 4 разнородных источника (реляционный XLSX, иерархический XML, JSON, неструктурированный текст).
- **2.3. Подготовка данных:** очистка, аннотирование текстов (TF-IDF + SVD), слияние данных по оси «Время», построение схемы «Звезда» (Parquet + SQLite).
- **2.4. Анализ и ML:** проверка гипотез (сезонность, правило Парето, RFM-сегментация, дни/часы, однократные покупки), обучение ML-моделей (классификация тональности и прогноз продаж) с замерами времени.
- **2.5. Сравнительная оценка:** бенчмарки форматов (XLSX vs CSV vs Parquet), агрегаций (pandas vs SQLite) и ML-моделей (LogReg vs LinearSVC vs RandomForest).
- **2.6. Дашборд:** интерактивное Streamlit-приложение для визуализации 5 гипотез.
